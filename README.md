# Protus Studio // Creative Direction & Web Design 

An editorial-inspired, high-performance digital portfolio built to showcase brand identity, layout architecture, and interactive web experiences. Designed and engineered from the ground up without the use of heavy frameworks.

### ⊙ System Architecture
This portfolio is an exercise in brutalist minimalism and technical precision:
* **Zero Dependencies**: Built entirely with pure, vanilla HTML5, CSS3, and JavaScript. 
* **Fluid Layouts**: Utilizes modern CSS `clamp()` functions for seamless typography scaling across mobile, tablet, and ultra-wide displays.
* **Interactive Canvas**: Features the *Zenith Poster Studio* module, a custom 2D canvas generative art engine that runs in real-time.
* **Frictionless Reviews**: Includes a bespoke, client-side review portal utilizing `localStorage` and dynamic avatar generation.

### ⊙ Performance
By stripping away massive libraries like React or Tailwind, the site achieves instant load times, perfect accessibility scores, and pristine layout shifts.
